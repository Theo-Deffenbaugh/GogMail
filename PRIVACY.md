# Privacy Policy

GogMail is the OAuth client configuration for a personal-use installation of the open-source gog (gogcli) command-line tool. It is used only by the owner of this repository.

The application runs locally on the owner's own computers. It accesses only the owner's own Google account data (Gmail, read-only scope) and displays it only to the owner. No data is collected, stored on third-party servers, shared, or sold. OAuth tokens are stored locally in the operating system credential store. Access can be revoked at any time at https://myaccount.google.com/permissions.

Contact: the repository owner, via GitHub issues on this repository.
